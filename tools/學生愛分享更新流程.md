# 學生愛分享篇數與流量 — 更新流程

> 以後學生愛分享的篇數與流量更新，一律在**網站健檢這個專案**進行（與新聞數量相同）。
> 本文記錄 2026-08 建置學生愛分享儀表板時的原始抓取方法，供日後更新沿用。

## 一、數字的定義

| 名詞 | 定義 |
| --- | --- |
| 累計篇數 | `www.fcu.edu.tw/share/` 全部文章中，標題可對應到本系者（不分年度） |
| 115學年度新增 | 發佈日 ≥ `CUT`（目前 `2026-08-01`）的篇數 |
| 瀏覽次數 | GA4 在 `gaSince ~ gaUntil` 區間內該篇文章頁的 pageViews，**不是**全站歷史累計 |
| 平均每篇瀏覽 | 本系瀏覽次數合計 ÷ 累計篇數 |
| 排名 | 只排「有產出」的學系（0 篇不佔名次），篇數與瀏覽次數各排一次 |

學生愛分享是**長期可瀏覽、不具時效性**的學生與系友故事，舊文章仍會持續累積瀏覽，
因此熱門排行採全站已知網址，而非只看統計期間內發佈者。

## 二、四條資料來源（原始抓取方式）

### 1. 文章清單 — 校網 JSON API

```
https://www.fcu.edu.tw/wp-json/api/share?offset=0&limit=100
```

分頁抓到回傳空陣列為止，存成 `share_full.json`（全部）與 `share_since_cut.json`（CUT 後）。

### 2. 瀏覽數 — GA4 Data API

GA4 property `258034980`，`pagePath` 以 `/share` 開頭，區間固定為 `CUT` ~ **昨天**
（避免當天資料未跑完而低估）。另取使用者數、平均停留時間、最大流量來源／媒介。

**服務帳戶金鑰不放進本專案**（本專案是公開 repo）。預設沿用原位置
`Z:\12.Claude專屬資料夾\工具程式\claude code\grand-quarter-500104-t6-e6073fb673e7.json`，
要換位置時設環境變數 `FCU_GA4_KEY`。

### 3. 學系歸屬 — 從標題反查

文章標題格式是「…｜逢甲資工系 林旻彥」，用 `ALIAS` 簡稱表（資工系→資訊工程學系…）
對照 `學院系列表.xlsx` 的正式系所全名。**簡稱沒收錄的一律視為「未對應系所」而不是亂猜**，
新增文章若出現新簡稱，要回頭補 `map_share_depts.py` 的 `ALIAS`，
否則該系的篇數會少算（目前 165 篇中有 3 篇未對應：逢甲創設系、RMIT-FCU、SJSU-FCU 雙聯學位）。

### 4. 學系對應健檢 id — 系所全名直接比對

`tools/extract-share.js` 以學系**全名**對應 `tools/depts.json`，目前 37 個有產出的學系全數對上（162 篇）。

## 四、例行更新五步驟

```bash
python tools/share-pipeline/fetch_share_stats.py     # 1. 抓文章清單
python tools/share-pipeline/fetch_share_ga4.py       # 2. 抓 GA4 流量（需金鑰）
python tools/share-pipeline/map_share_depts.py       # 3. 標題 → 學系（看 unmatched 清單補 ALIAS）
python tools/share-pipeline/build_share_dashboard.py # 4. 重新產生 student-share.html
node tools/extract-share.js && python tools/sync-share-to-healthcheck.py   # 5. 同步進健檢儀表板
```

⚠️ 第 4 步會**整個覆蓋** `student-share.html`（它是產出檔，版面要改請改
`build_share_dashboard.py` 裡的 `TEMPLATE`）。第 5 步會自動備份 `health-check.html`。

⚠️ **跑第 4 步前先確認 TEMPLATE 沒有落後於現場檔**。2026-10-02 就遇到：現場的
`student-share.html` 被手動改成 115學年度、加了 `const AY`、側欄多一顆「返回AI成果首頁」，
而 TEMPLATE 還停在 114學年度，直接重建會整個倒退。確認方式是先產到暫存檔再跟現場檔 diff
（忽略 `const SHARE_RAW`／`GA4_SHARE`／`COLLEGES`／`BUILT_AT` 這幾行資料），版面差異為 0 才正式覆蓋。
學年度切換現在只要改 `build_share_dashboard.py` 最上面的 `CUT`／`AY` 兩行。

## 五、健檢儀表板那一頁放了什麼

各系頁面的「🎓 學生愛分享」分頁（`==SHARE_JS_START==` 區塊）：

- 五格統計：累計篇數／115學年度新增／瀏覽次數合計／平均每篇瀏覽／最近發佈日期
- 全校比較條：本系篇數 vs 全校平均（橘線），右側是篇數與瀏覽的全校排名
- 0 篇的學系：改顯示提醒卡，說明學生愛分享是什麼、建議推薦 1–2 位學生或系友
- 年度發佈趨勢長條圖（各系共用同一年度刻度，便於互相比較）
- 文章列表，可切換「依發佈日期／依瀏覽次數」排序

開放範圍同樣用一行開關控制：

```javascript
const SH_DEPTS = 'all';   // 僅開放部分學系 → const SH_DEPTS = ['inde'];
```

⚠️ `switchTab()` 靠 DOM 索引對位，**分頁按鈕與面板的順序必須一致**；
目前順序為 健檢總覽／頁面查核紀錄／招生連結查核／新聞成效／學生愛分享／評分標準／改善回饋填寫。
